# Lumine 현재 구현 기능 패치노트

> 기준일: 2026-09-04  
> 범위: 현재 저장소의 모바일 앱 및 서버 구현 기준  
> 상태: 출시 예정 기능이 아닌, 코드에 구현된 기능만 정리  
> 관리 원칙: 기능 구현이 완료될 때마다 해당 변경과 제공 범위를 이 문서에 함께 갱신

## 이번 버전 핵심

- iOS·Android 네이티브 앱에서 감정 일기와 마음 상태 확인을 제공한다.
- 로그인 사용자의 서버 데이터를 계정별로 분리하고, 게스트 기록은 사용자 동의 후 계정으로 이전할 수 있다.
- 자동 임시 저장, 오프라인 대기열, 재전송, 충돌 감지, 삭제 취소를 통해 기록 작성 안정성을 강화했다.
- 주간·월간 마음 리포트에서 기록과 마음 상태의 흐름을 이전 기간과 비교해 돌아볼 수 있다.
- 위기 가능성이 감지되거나 사용자가 도움이 필요할 때 즉시 이용할 수 있는 안전 지원 동선을 제공한다.

## 시작 및 계정

### 추가됨

- 스플래시와 서비스 소개 화면을 제공한다.
- 카카오 및 Google 계정으로 로그인할 수 있다.
- 로그인하지 않고 게스트로 앱을 사용할 수 있다.
- 기존 로그인 세션을 앱 시작 시 복원한다.
- 최초 로그인 후 성별, 생년월일, 필수 약관 동의를 포함한 프로필 설정을 진행한다.
- 전체 동의와 개별 약관 동의를 모두 지원한다.
- 앱 안에서 이용약관과 개인정보처리방침을 확인할 수 있다.
- 계정 로그아웃을 지원하며 연동된 소셜 로그인 세션도 함께 정리한다.

### 보안 및 데이터 분리

- 소셜 로그인 토큰을 서버에서 검증한 뒤 서비스용 인증 토큰을 발급한다.
- 일기, 마음 확인 결과, 프로필, 내보내기 및 삭제 요청을 로그인 사용자 기준으로 분리한다.
- 다른 사용자의 식별자를 요청에 포함하더라도 해당 사용자의 데이터에 접근할 수 없도록 서버 인증 주체를 기준으로 처리한다.
- 기기 내 세션과 사용자별 캐시는 보안 저장소를 사용하고 계정 또는 게스트 단위로 구분한다.

## 홈

### 추가됨

- 시간대와 사용자 이름에 맞춘 인사말을 표시한다.
- 이번 주 감정 일기를 작성한 날짜 수를 월요일부터 일요일까지 달력 형태로 보여준다.
- 이번 주에 자주 나타난 감정을 요약하고 주간·월간 마음 리포트로 이동할 수 있다.
- 최근 감정 일기 3개를 미리 보고 전체 기록으로 이동할 수 있다.
- 감정 일기 작성과 마음 상태 확인으로 바로 이동하는 빠른 실행을 제공한다.
- 마음 확인 기록이 없거나 마지막 확인 후 30일 이상 지난 경우 다시 확인할 시점을 안내한다.
- 홈과 전체 기록을 오가는 하단 탭 내비게이션을 제공한다.

## 주간·월간 마음 리포트

### 추가됨

- 홈의 주간 요약에서 상세 마음 리포트로 이동할 수 있다.
- 월요일부터 일요일까지의 주간 리포트와 달력 월 기준의 월간 리포트를 전환해 볼 수 있다.
- 현재 기간에 감정 일기를 기록한 일수와 기간의 전체·경과 일수를 표시한다.
- 진행 중인 기간을 직전 기간의 동일한 경과 일수와 비교해 기록 일수 변화를 보여준다.
- 자주 느낀 감정과 감정별 등장 횟수, 이전 기간 대비 변화를 제공한다.
- 기록한 감정을 바탕으로 편안했던 날과 마음이 무거웠던 날을 제시한다.
- 대표 날짜를 누르면 해당 감정 일기 상세 화면으로 이동한다.
- 현재와 이전 기간의 마음 상태 확인 결과를 비교해 가벼워짐, 비슷함, 무거워짐으로 안내한다.
- 안전 확인이 필요한 결과가 기간 내에 있으면 일반적인 변화 표현보다 안전 지원 안내를 우선한다.
- 기록 흐름에 따라 다음 기간에 시도할 수 있는 작은 행동 한 가지를 제안한다.
- 기록이나 비교 데이터가 부족하면 임의의 해석 대신 부족 상태와 다음 기록 동선을 안내한다.
- 마음 상태 비교용 수치는 내부 계산에만 사용하며 사용자 화면에는 점수나 진단 표현을 노출하지 않는다.

## 마음 상태 확인

### 추가됨

- 약 5분 분량의 단계형 마음 상태 확인을 제공한다.
- 시작 전 비공개 처리, 비진단 목적, 최근 상태를 기준으로 답변해야 한다는 안내를 제공한다.
- 객관식 문항과 선택형 자유 입력 문항을 지원한다.
- 현재 문항 수와 전체 진행률을 표시한다.
- 서버에서 최신 문항을 불러오며, 연결 실패 시 앱 내 기본 문항으로 계속 진행할 수 있다.
- 필수 문항의 미응답을 방지하고 안전 관련 문항에서는 추가 안내를 표시한다.
- 제출 후 현재 상태 요약, 위로 메시지, 추천 행동, 다음 확인 권장일을 제공한다.
- 안전 확인이 필요한 결과에는 일반 결과와 분리된 안전 안내 화면을 먼저 제공한다.
- 로그인 사용자의 답변과 결과를 서버에 저장하고 최근 이력을 조회한다.
- 게스트 결과는 기기에 저장하며 로그인 후 이전할 수 있도록 대기시킨다.
- AI 기반 결과 문장 생성을 지원하고, 외부 생성 기능을 사용할 수 없을 때는 규칙 기반 결과로 대체한다.

## 감정 일기

### 추가됨

- 오늘 날짜의 감정 일기를 새로 작성하거나 다시 편집할 수 있다.
- 16개의 기본 감정 중 1~3개를 선택할 수 있다.
- 최대 8자의 사용자 정의 감정을 추가할 수 있다.
- 감정과 함께 선택 입력 방식의 본문을 기록할 수 있다.
- 저장 후 기록 내용에 맞춘 위로 메시지와 저장 완료 화면을 제공한다.
- 날짜별 기록 목록과 상세 화면을 제공한다.
- 기록 목록에서 자주 나타난 감정과 간단한 감정 흐름을 확인할 수 있다.
- 상세 화면에서 감정, 본문, 날짜, 위로 메시지를 확인하고 기록을 수정할 수 있다.
- 로그인 사용자는 날짜별로 하나의 기록을 유지하며 같은 날짜를 다시 저장하면 기존 기록을 갱신한다.

### 작성 안정성 개선

- 감정, 본문, 사용자 정의 감정을 작성 중 자동으로 임시 저장한다.
- 앱을 나갔다 돌아오거나 다시 실행해도 해당 사용자와 날짜의 임시 기록을 복원한다.
- 저장 실패 시 입력한 감정과 본문을 유지하고 오류 안내와 재시도를 제공한다.
- 로그인 상태에서는 서버 전송 전에 기기 내 대기열에 먼저 저장해 기록 유실 가능성을 줄인다.
- 기록마다 동기화 완료, 로컬 전용, 전송 대기, 실패, 충돌 상태를 구분해 표시한다.
- 대기 또는 실패한 기록을 사용자가 직접 다시 전송할 수 있다.
- 네트워크가 복구되거나 앱이 다시 활성화되면 재시도 가능한 작업을 자동 전송한다.
- 서버 기록의 버전을 비교해 다른 기기나 세션의 최신 변경을 실수로 덮어쓰지 않도록 한다.
- 충돌이 발생한 기록은 자동으로 버리지 않고 충돌 상태로 보존한다.

### 삭제 및 복구

- 상세 화면에서 감정 일기를 삭제할 수 있다.
- 삭제 후 5초 동안 실행 취소할 수 있는 안내 바를 제공한다.
- 실행 취소하면 감정, 본문, 위로 메시지와 기존 동기화 작업을 삭제 전 상태로 복원한다.
- 실행 취소 시간이 지난 뒤 서버 삭제를 진행한다.
- 오프라인에서 요청한 삭제는 대기열에 보관하고 연결이 복구되면 다시 시도한다.

## 게스트 기록 이전 및 동기화

### 추가됨

- 게스트가 로그인하면 기기 기록을 계정으로 이전할지 먼저 확인한다.
- 사용자가 이전을 거절해도 기록을 삭제하지 않으며 메뉴에서 나중에 다시 시도할 수 있다.
- 동기화 중, 완료, 일부 확인 필요 상태와 처리 건수를 표시한다.
- 감정 일기와 마음 확인 결과를 항목별로 이전해 일부 항목 실패가 전체 이전을 막지 않도록 한다.
- 이미 이전한 항목은 가져오기 영수증을 통해 중복 생성하지 않는다.
- 같은 날짜의 서버 일기와 게스트 일기가 충돌하면 서버 기록을 유지하고 게스트 기록은 기기에 보존한다.
- 실패하거나 충돌한 항목은 대기열에 남겨 사용자가 확인하거나 다시 시도할 수 있다.
- 이전 진행 화면에서도 안전 지원 화면으로 바로 이동할 수 있다.

## 안전 지원

### 추가됨

- 메뉴와 마음 확인 결과에서 전용 도움 요청 화면으로 이동할 수 있다.
- 자살예방상담전화 109, 긴급신고 119, 보건복지상담센터 129로 바로 전화할 수 있다.
- 도움을 요청하기 어려운 상황을 위해 미리 작성된 도움 요청 문구를 운영체제 공유 기능으로 전달할 수 있다.
- 안전 지원 화면에서 감정 일기 작성으로 이동할 수 있다.
- 서버에서도 안전 지원 연락처 정보를 제공한다.

## 메뉴 및 데이터 관리

### 추가됨

- 로그인 상태, 사용자 정보, 감정 일기 수, 마음 확인 수를 요약한다.
- 게스트 사용자는 메뉴에서 로그인 화면으로 이동할 수 있다.
- 게스트 기록의 이전 상태를 확인하고 이전을 수동으로 다시 실행할 수 있다.
- 앱 버전과 법적 문서를 확인할 수 있다.
- 사용자의 프로필, 전체 감정 일기, 마음 확인 답변 및 결과를 UTF-8 JSON 파일로 내보낼 수 있다.
- 내보낸 파일을 운영체제 공유 또는 파일 저장 기능으로 전달할 수 있다.
- 확인 절차를 거쳐 Lumine 계정과 서버 데이터를 삭제할 수 있다.
- 계정 삭제 시 서버의 사용자 정보, 일기, 마음 확인 기록, 게스트 이전 이력을 함께 삭제한다.
- 계정 삭제 후 현재 계정의 기기 내 세션과 캐시도 정리한다.
- Lumine 계정 삭제는 연결된 카카오 또는 Google 계정 자체를 삭제하지 않는다.

## 서버 및 운영 기반

### 추가됨

- Kotlin·Spring Boot 기반 API와 JWT 인증을 사용한다.
- 사용자 프로필, 감정 일기, 마음 확인, 게스트 가져오기, 데이터 내보내기·삭제 API를 제공한다.
- 감정 일기 저장과 삭제에 버전 기반 낙관적 잠금을 적용한다.
- 게스트 기록 가져오기에 항목 단위 결과와 중복 방지 처리를 적용한다.
- 개발 환경의 H2와 운영 환경의 PostgreSQL 구성을 지원한다.
- 데이터베이스 스키마 변경을 마이그레이션으로 관리한다.
- 감정 일기 위로 문장과 마음 확인 결과 생성은 외부 AI 연동 및 기본 대체 로직을 함께 지원한다.

## 현재 제공 범위

- 마음 상태 확인은 의료 진단이나 전문 상담을 대체하지 않는다.
- 마음 확인 작성 중 임시 저장과 제출 후 개별 결과 삭제는 아직 제공하지 않는다.
- 감정 일기 삭제 복구는 장기 보관함이 아닌 삭제 직후 5초 실행 취소 방식이다.
- 자동 재전송은 네트워크 복구 또는 앱 활성화 시 동작하며, 종료된 앱의 상시 백그라운드 동기화는 제공하지 않는다.
- 서버 충돌 기록은 안전하게 보존하지만 변경 내용을 자동 병합하는 화면은 제공하지 않는다.
- 실제 카카오·Google 로그인은 각 플랫폼의 운영용 앱 키와 서버 설정이 필요하다.
